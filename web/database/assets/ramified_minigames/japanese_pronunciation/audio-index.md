# Japanese Kana pronunciation audio index

This index maps every browser MP3 to the Hiragana and Katakana tiles that use it. The recordings are public-domain files listed in `sources.json`; MP3 files are browser-compatible derivatives of the corresponding Ogg sources.

Hiragana and Katakana for the same mora intentionally share one recording.

Source collection: [Audio files of hiragana (set by Hakatanoshio117117)](https://commons.wikimedia.org/wiki/Category:Audio_files_of_hiragana_(set_by_Hakatanoshio117117)).

## Audit result

- All 71 game keys, Hiragana, Katakana, MP3 filenames, and Wikimedia source filenames are in one-to-one agreement.
- Wikimedia metadata descriptions explicitly identify the expected Hiragana for all 71 source files.
- Acoustic fingerprints of all 71 local Ogg clips match their same-named original source recordings; no swapped recording was found.
- Every MP3 has the duration of its same-named local Ogg source within normal codec padding tolerance.

## Pronunciation notes

- `お` / `オ` and `を` / `ヲ` are normally pronounced the same (`o`) in modern standard Japanese. Their local decoded audio is intentionally identical.
- `じ` / `ジ` and `ぢ` / `ヂ` are normally pronounced alike in modern standard Japanese, despite separate game keys `ji` and `dji`.
- `ず` / `ズ` and `づ` / `ヅ` are likewise normally pronounced alike, despite separate game keys `zu` and `dzu`.
- `ふ` / `フ` is shown with Hepburn-style `fu`; its Wikimedia filename uses the alternative spelling `hu`.
- `ち` / `チ` is shown as `chi`; its Wikimedia filename uses `ti`.
