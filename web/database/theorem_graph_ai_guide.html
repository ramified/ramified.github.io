Turn a paper into a dependency graph

This page does not read papers itself. It writes a prompt: give that prompt, together with your paper, to any AI chat, and it returns a graph of the paper's results (definitions, lemmas, theorems) with arrows for "used in the proof of". Import the result into the calculator to view and edit it.

  1. 1 · SET UPChoose a mode, name the paper, copy the prompt below.
  2. 2 · ASK AN AIPaste the prompt into ChatGPT, Claude, etc. and attach the paper (PDF or LaTeX source). Longer papers work best as LaTeX.
  3. 3 · IMPORTPress the copy button on the AI's code block (don't select text by hand). In the calculator: Import / Export → Import → Paste text, paste, press import.

FAQ

Is the graph guaranteed correct? No. The AI may miss or invent dependencies. Arrows it could not find in the text are marked "inferred" in the arrow's remark; check them against the paper.

The AI says it cannot see my paper. Attach the file in the same chat, or paste the LaTeX source. The prompt tells the AI to stop and ask if nothing is attached.

Import fails, or the pasted text shows &#x20;, stray \ at line ends, or \_\_title\_\_. That is the chat window's markdown rendering damaging the text. Copy with the code block's own copy button, or ask the AI: "put the JSON in one json code block and nothing else".

The prompt is generated in your browser; nothing is uploaded.
