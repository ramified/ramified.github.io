`node js/ramified_minigames_r13_audit.js` 是本轮新增的非首错停止诊断入口，逐个调用测试文件中声明的测试函数并报告全部失败，失败时退出码为 1。它按源码定义顺序执行，不替代各套件的正常入口；统计的是测试结果，不是玩家可见缺陷数。

三套标准入口与逐项诊断入口均通过。原有失败按真实缺陷、过期夹具和测试环境分别处理，未跳过失败用例。

## 已修复

1. **实际台球缺陷：复制状态改变球半径。** 旧预设半径 0.05 对应的推导物理长度超过当前滑块范围，`cloneState()` 经导出／重建后默认半径变成 0.05715。摆球布局按原半径生成，新增球却用新半径，产生重叠误判。现在复制明确保留原默认球半径和球袋半径，新增半径保持断言。现有小游戏摆球与计算器摆球回归同时通过；未改变滑块范围或改写预设。
2. **Hex 悬停测试初始化失真。** 旧版调试页面随机开局后，测试实际运行在五子棋上；测试环境还缺少 Hex 模块，且固定屏幕点不保证命中当前棋盘。用例现明确采用玩家初始化、预载实际 Hex 模块，从当前几何取得有效格中心，并断言游戏类型；仍保留 399/400ms 阈值、同格移动不重置、离格清除检查。
3. **开放 4×4 规则夹具过期。** 多个规则用例引用已移除的 `classic-4x4`，实际回退到带边界粘合的棋盘。改为测试内显式开放 4×4 预设，保持原移动、合并、无效移动、满盘及炸弹断言，不把旧预设加回产品目录。
4. **计算器魔方测试过期。** 已移除 2×2×2 文件，现使用目录注册的 3×3×3 文件并经过真实导入规范化，明确检查 9×12 尺寸、21 对粘合边及移除格。

5. **异步导入测试缺少等待。** 状态及预设导入已异步加载依赖；测试现在等待导入完成后再操作，异步用例串行执行，保留键盘、滑动、撤销／重做、状态往返和结果卡断言。
6. **测试环境与目录更新。** 通用 headless 环境预载实际游戏模块，只在非随机专项用例中固定启动；随机专项仍执行真实随机入口。目录断言检查当前注册项，规则测试使用独立旧版夹具（含 2×2×2 魔方），不恢复已下架产品预设。预设游戏类型归属检查读取导出对象，避免把示例注释识别为实际字段。
7. **当前交互步骤补齐。** 围棋两次停着后检查计分复核并显式确认结果；四子棋添加入口前启用编辑控件；URL 预设导入检查准备预览。当前默认棋盘、棋子数量及方向游戏共用控件的断言与实现一致。
