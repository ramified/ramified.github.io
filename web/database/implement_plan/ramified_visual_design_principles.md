# ramified 首页与 Math Workspace 的界面审美说明

来源：用户于 2026-10-28 提供的 Claude 设计建议。以下九部分保留用户提供的规范内容；本文件作为后续设计与实现依据，不表示已完成实现。

## 一、定位

- 这是一个纯数学家自己做的浏览器工具集，使用者是数学系学生和研究者。
- 气质应当像一本印刷精良的讲义或手稿：克制、清晰、有数学味。不要做成 SaaS 产品落地页。
- 首页的唯一任务是把人带进 Math Workspace。其他一切都要安静。

## 二、必须避开的“AI 味”

作者收到过“网站像 AI 生成的”反馈。以下做法一律不要用：

- 紫蓝渐变、霓虹光晕、毛玻璃、大面积渐变背景。
- 一排大小相同、圆角相同、阴影相同的卡片。
- 每个标题上方都放一行全大写的小标签（eyebrow）。
- 用 emoji 或通用图标库的图标当装饰。
- 标题里只给一个词换颜色或斜体。
- 每个区块都做“淡入加上滑”的入场动画，每张卡片都做悬停上浮。
- 米色底加赤陶色强调，或黑底加荧光绿强调，这两种也是常见的 AI 默认配色。
- 文案里的“→”箭头、用中点连接的元信息串，以及“WORD — 片段”式标签。

## 三、配色（日间）

- 纸色背景 `#F1F3EF`，是带一点灰绿的纸白，不是纯白。
- 面板 `#FAFBF8`。
- 墨色文字 `#18212B`，次要文字 `#55606B`。
- 分隔线 `#CBD2CC`。
- 唯一强调色是深青 `#0E6B63`，浅色底 `#D3E8E3`。
- 强调色只用在“主按钮、链接、被选中的东西”上，不做装饰。
- 暗色模式用同一套语义变量重新取值：背景 `#12181D`，强调色 `#54B9AC`。
- 正文对比度至少 4.5:1。

## 四、字体

- 标题和公式用衬线体，推荐 STIX Two Text，它是为数学排版设计的。中文回退到 Noto Serif SC。
- 界面文字和说明用 Source Sans 3，中文回退到 Noto Sans SC。
- 字号层级：主标题约 60px，二级标题 28px，正文 17px，说明 15px。
- 正文行宽控制在 60 个字符以内，衬线正文行高不低于 1.6。
- 数学符号（λ、χ、det）用衬线斜体，与界面文字区分开。

## 五、版式

- 整页左对齐，最大宽度约 1120px，不要居中堆叠。
- 首屏左边是标题、一句说明和一个主按钮，右边是工作区的示意图。
- 第二部分“Also on this site”用横向条目：左边是小插图，右边是文字，条目之间只用一条细线分隔，不要做成卡片。
- Classic index 做成页面底部一条安静的带状提示，不要和工作区争抢视线。
- 手机端（窄于 860px）改为单列，插图缩小。

## 六、插图（全页唯一的“重点”）

- 首屏的工作区示意图用 SVG 手绘：左边 Assets 列表，右边几个计算器面板，内容用真实数学例子。例子必须是对的，比如 λ=(4,2,1) 对应 35 个标准表，P² 上的 O(1) 满足 χ=3。
- 示意图后面用一块不透明的浅青色偏移块当“阴影”，不要用柔和的灰色模糊阴影。
- Theorem Graph 和 Minigames 的插图风格要统一：同样的线宽、同样的配色，只用强调色和墨色。
- 所有插图用 `currentColor` 或 CSS 变量着色，这样暗色模式会自动适配。

## 七、动效与可访问性

- 默认不加主动动效。链接悬停只做下划线加粗，按钮悬停只做下划线。
- 所有可聚焦元素都要有清楚的 `:focus-visible` 描边，并遵守 `prefers-reduced-motion`。
- 纯装饰的 SVG 加 `aria-hidden`，有信息量的 SVG 加 `role="img"` 和文字说明。

## 八、文案

- 用动词开头，一个按钮只说一件事，比如“Open the workspace”。
- 不用夸张形容词，不自夸，不写“powerful”之类的词。
- 不稳定的地方如实说明（“A few things in the workspace are still being fixed”），并给出退路。

## 九、延伸到 Math Workspace 本身

- 沿用同一套配色、字体和线条语言，让首页和工作区看起来是同一个作品。
- Assets 列表里，被选中的资产用浅青色底加左侧一条强调色竖线标出。
- 面板标题统一为小号半粗体、灰色，面板之间用细线分隔，不要给每个面板加不同颜色。

## 实施时的解释与边界

- 第三部分限制装饰性强调色，第六部分明确允许数学插图使用强调色；将后者视为有内容作用的图示，不扩大到装饰标签、标点、光晕等。
- 保留上面的原始数学字体要求。正式数学排版时，变量通常用斜体，`det` 等算子通常用正体；实现时应区分变量与算子，而不是机械地把全部数学内容设为斜体。
- 文件名已于 2026-10-28 按用户要求交换：`index.html` 是新设计，`index_classic.html` 是原计算器目录。新首页仅在底部带状区保留一个 Classic index 链接。
- 修改计算器编辑行为及 Minigames 用户界面时，仍须遵守根目录 AGENTS.md 的专项要求。此规范本身不授权扩展修改范围。

## 后续打磨约束（2026-10-28）

- 已修正的行为不得回退：网格渐隐仅作用于 `.hero::before`；Classic 入口仅一处；Minigames 保留右出左入的虚线粘合箭头；变量与算子采用不同的正斜体规则。
- 桌面与手机工作区 SVG 展示相同数学例子，手机重排面板以避免文字过小。两幅图由 CSS 控制只显示一幅，不新增内容区块。
- 图内必要边线使用 `--diagram-rule`，区别于页面细分隔线 `--rule`，确保暗色下仍清晰。
- 教程占位说明使用普通文本，不加按钮语义、tabindex 或暗示点击的样式。
- 不加新装饰或动效。首页定稿后再提取共享变量给 Math Workspace；此轮不修改工作区。
- `archive/homepage-concepts/` 中的旧方案已弃用，不再用作设计候选或样式来源。
