## 范围与判断

用户希望在独立页面中尝试 Claude 建议，保留原页供比较。当前 `ramified_minigames.html` 已经有玩家外壳，普通游戏与开发工具已经基本分离；Claude 对编辑器层级的判断更适合旧版页面，不能直接据此重写当前流程。

实际游戏共有 11 款，包括连连看。游戏规则、棋盘渲染、边界连接、AI、默认棋盘与设置、按键绑定、撤销与存档流程继续复用现有实现。

粘合箭头保留：它们包含配对和方向的信息，玩家可以学习，不应仅因不熟悉而移除。入门页补充静态边界配对示意图和中英文解释，不引入装饰动画。

本页可试验原页已有固定 4:3、黑色标题栏及分页规则之外的版式；实验结果尚未被选为正式方案，不将这些变化推广到原页。

## 实现隔离

- `css/ramified_minigames_study.css` 仅新页加载，所有规则限定于 `.design-study`。没有修改 `site.css`、共享棋盘 CSS 或 Mosaic 页面。
- `js/ramified_minigames_study_build.js` 从现有页生成独立 HTML 与玩家脚本。生成玩家脚本只改变展示页数、排序、说明及存档适配器；规则引擎与绘制代码不复制、不改动。
- 实验玩家脚本为 `js/ramified_minigames_study_player.js`，更新原玩家外壳后可运行 `node js/ramified_minigames_study_build.js` 同步。
- 本地棋局存档键加 `design-study:` 前缀，避免覆盖、恢复或迁移原版棋局。显示、声音、按键等原引擎偏好继续共用。
- `js/ramified_minigames_study.js` 移动已有 DOM 控件到工作坊、HUD 或游戏操作抽屉，保留 ID、监听器与按游戏显示条件。
- Workshop 位于设置的“常规”页，默认关闭，包含现有调试、翻译检查、音效实验和文件工具。台球浮动工具放进游戏操作抽屉，避免盖住手机棋盘。
- 新增静态和动态文字均使用明确的双语键；实验附加目录单独注册，原目录不变。共享 i18n 测试覆盖新页。

## 没有采用的建议

- 不取消数学粘合箭头，也不新增跨边界幽灵棋子、镜像动画或 Show gluing 开关。这些需要深入绘制与输入行为，超出本轮外壳实验。
- 不更换棋子配色、2048 色阶、落子反馈、胜负覆盖层或声音规则，避免外壳工作变成游戏逻辑与美术重写。声音本来默认关闭，新增快捷按钮沿用原音效开关。
- 不增加随机棋盘入口、手势系统、棋盘主题缩略图或首次游玩记录。继续使用现有准备、显示设置和操作系统。
- 手机外框利用可用高度；原版固定 4:3 保持原状，供直接比较。
